# Datos pendientes del cliente

Estas preguntas mejorarían la precisión del sitio, pero ninguna bloquea la versión actual. Hasta recibir respuesta se mantiene copy prudente.

| Prioridad | Pregunta | Dónde mejoraría el contenido | Copy prudente actual |
|---|---|---|---|
| Alta | ¿Cuál es la dirección exacta del consultorio y hay un enlace confirmado de Google Maps? | Footer, Consultorio, FAQ y datos estructurados | La dirección exacta se confirma al agendar por WhatsApp. |
| Alta | ¿Cuál es el horario habitual por día y cómo cambia los sábados? | Footer, FAQ y mensajes previos a la cita | Agenda y citas sujetas a disponibilidad confirmada. |
| Alta | ¿Cómo manejan las urgencias fuera del horario habitual? | Home, página de urgencias y campañas | No se promete atención 24/7; se pide consultar disponibilidad. |
| Media | ¿Cuál es el valor actual de la primera valoración y cambia según especialidad? | FAQ y respuestas sobre precios | Se invita a consultar el valor antes de agendar. |
| Media | ¿Qué formas de pago están disponibles? | FAQ previa a la cita | No se menciona ninguna forma de pago. |
| Media | ¿La primera valoración incluye radiografías o se solicitan aparte cuando hacen falta? | FAQ de servicios | Solo se indica que pueden requerirse estudios adicionales. |
| Media | ¿Qué servicios realiza directamente Nataly y cuáles dependen de la agenda de cada especialista? | Perfiles, catálogo y mensajes de agenda | Se describen roles generales y se confirma disponibilidad por WhatsApp. |
| Media | ¿Hay credenciales, formación o asociaciones que la cliente quiera publicar y pueda respaldar? | Página de Equipo | Los perfiles solo incluyen los roles confirmados. |
| Baja | ¿Existe un perfil de Google Business verificado y hay autorización para mostrar calificación y número de reseñas? | Bloque de reputación | El bloque permanece desactivado. |
| Alta | ¿Existe autorización escrita para publicar el caso de prótesis? | Página de prótesis | El caso permanece desactivado y sus rutas no se envían al navegador. |

## No preguntar salvo que vaya a publicarse

No se necesitan cifras de pacientes, tasas de éxito, premios, superlativos ni promesas de resultados. Esos datos no mejorarían la voz de la web y aumentarían el riesgo editorial.
