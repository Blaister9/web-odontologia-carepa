# Preservación SEO

Fecha de revisión: 2026-08-22

## Elementos preservados

- Todas las rutas públicas, incluidas las 12 páginas de servicio y las 6 rutas de campaña.
- Los H1 locales de las páginas de servicio: tratamiento + “en Carepa”.
- El title principal y la intención “odontología en Carepa”.
- Canonical, robots, Open Graph, Twitter cards y `Dentist` JSON-LD.
- `Service` y `FAQPage` JSON-LD en cada detalle de servicio.
- Los nombres clínicos de servicios y las menciones locales útiles.
- Los enlaces internos hacia servicios relacionados, equipo, consultorio y selector de necesidad.
- La lista de keywords configurada; no se añadieron repeticiones visibles para forzar posicionamiento.

## Elementos mejorados

- Las meta descriptions se hicieron más cortas y naturales sin retirar el tratamiento ni Carepa.
- El H1 de `/servicios` pasó de “Catálogo de atención odontológica en Carepa” a “Servicios odontológicos en Carepa”, con intención más directa.
- El contenido informativo de cada servicio conserva beneficios, señales para consultar, proceso y FAQ, pero elimina frases duplicadas de conversión.
- Los CTA y mensajes de WhatsApp ya no repiten “Carepa”, “orientación” y “valoración” en cada frase.

## Cambios deliberadamente no realizados

- No se eliminaron páginas ni bloques FAQ.
- No se cambiaron slugs, rutas de campaña, parámetros UTM ni destinos de WhatsApp.
- No se modificaron el layout, las imágenes, la jerarquía de encabezados ni los datos estructurados.
- No se añadieron precios, dirección, horario, credenciales ni claims para ampliar artificialmente el contenido.

## Riesgos revisados

- Reducir demasiado las páginas de servicio podía debilitar intención informativa; se conservaron sus secciones y preguntas.
- Repetir la ubicación en cada mensaje y cada oración podía parecer keyword stuffing; “Carepa” se mantiene donde aporta contexto.
- El caso clínico de prótesis permanece fuera del payload público mientras no exista autorización.
- Dirección, horario y precio siguen siendo datos pendientes; el copy actual evita información falsa sin ocultar el siguiente paso.
