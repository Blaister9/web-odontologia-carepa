- `PUBLIC-SAFE`: sin datos privados aparentes y, cuando hay paciente/procedimiento, con permiso confirmado por la cliente en esta tarea.

- `PRIVATE-DO-NOT-PUBLISH`: conversación privada; nunca se copió a `public/` ni se generó preview público.
