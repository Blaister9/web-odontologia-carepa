# Formatos públicos generados

Se prepararon cuatro fuentes `PUBLIC-SAFE` de calidad útil: IMG-005 (consultorio), IMG-004 (equipo), IMG-015 (procedimiento autorizado) e IMG-017 (Nataly). Para cada fuente se generaron:

- Feed: 1080×1080.
- Portrait: 1080×1350.
- Story / cover: 1080×1920.
- Meta horizontal: 1200×628.
- Google Business: 1200×900.

Rutas: `/marketing/media-v2/{feed,portrait,story,meta-horizontal,google-business}/`.

No hubo upscale. Cuando el original no cubría el canvas solicitado, Sharp mantuvo su tamaño útil y añadió un canvas editorial lavanda claro. No se aplicó retoque facial, blanqueamiento, modificación dental/corporal, reemplazo de fondo ni alteración generativa.

También se conservaron tres piezas terminadas `PUBLIC-SAFE` en `/marketing/media-v2/client-originals/`; no se incrustaron como UI web. Las piezas con promoción o disponibilidad dinámica, dirección dudosa, conversación privada o marca Meta AI no se copiaron.
